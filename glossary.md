# Glossary — Apache Kafka 4.3 Documentation

**ACL** — principal allowed/denied an operation from a host on a resource pattern (ch20)
**Acquisition lock** — share-group per-record exclusive claim (`share.record.lock.duration.ms`, 30 s); expiry redelivers (ch06)
**allow.everyone.if.no.acl.found** — default false: resources without ACLs are super-user-only (ch20)
**ApiVersionsRequest** — first request per connection; negotiates highest common version per API (ch08)
**application.id** — required Streams ID; prefixes group, state dir and internal topics (ch23, ch27)
**application.server** — unique host:port per Streams instance; needed for IQ discovery (ch28)
**Changelog topic** — compacted topic backing a state store; replayed to restore it (ch24, ch26)
**Co-partitioning** — equal partition count and partitioner on both join inputs (ch25)
**Committed message** — write on every ISR replica with ISR ≥ min.insync.replicas; consumer-visible (ch06, ch07)
**Connector / task** — connector splits a job into ≤ `tasks.max` tasks that copy data (ch21, ch22)
**Consumer lag** — log-end offset minus committed offset; client metric `records-lag-max` (ch10, ch14)
**Controller quorum** — KRaft voters; 2N+1 tolerate N failures, one active (ch15)
**Converter** — maps Connect data to/from bytes, independent of connector (ch21)
**Dead letter queue** — topic receiving records that fail conversion/transform/sink (ch21, ch22)
**Dynamic quorum (KIP-853)** — voters changed online; needs `kraft.version` ≥ 1 (ch02, ch15)
**Dynamic update mode** — broker config `read-only`, `per-broker` or `cluster-wide` (ch04)
**Eligible Leader Replicas (ELR)** — out-of-ISR replicas still safe to elect (KIP-966) (ch17)
**exactly_once_v2** — Streams EOS committing offsets, state and output atomically (ch24, ch27)
**Feature finalization** — raising feature levels via `kafka-features.sh` (ch15, ch17, ch30)
**Foreign-key join** — KTable-KTable join on a key from the left value; no co-partitioning (ch25)
**GlobalKTable** — table fully replicated to every instance; no co-partitioning, no time (ch24, ch25)
**Grace period** — how long a window accepts out-of-order records (ch24, ch25)
**group.protocol** — `classic` (default), `consumer` (KIP-848) or `streams` (KIP-1071) (ch17, ch23, ch29)
**Idempotent producer** — broker dedups retries by producer ID + sequence (ch06, ch20)
**Interactive Queries** — read-only lookups into Streams state stores (ch28)
**isolation.level** — `read_uncommitted` (default) or `read_committed` (ch06)
**ISR** — replicas within `replica.lag.time.max.ms` of the leader; only they can lead (ch07)
**Keystore / truststore** — node's private key+cert (secret) / trusted CAs (shareable) (ch18)
**KIP-1035** — 4.3 Streams keeps changelog offsets inside RocksDB (ch27, ch30)
**KIP-848** — incremental broker-driven consumer rebalance protocol, GA in 4.0 (ch17)
**KIP-890** — transaction server-side defense; epoch bump per transaction (ch17, ch30)
**KIP-896** — 4.0 removal of old protocol versions; peers must be ≥ 2.1 (ch02, ch30)
**KRaft** — Raft metadata mode replacing ZooKeeper; `__cluster_metadata` log (ch15, ch30)
**KStream** — record stream; each record is an INSERT (ch25)
**KTable** — changelog stream; each record UPSERTs its key, null = delete (ch23, ch25)
**Listener** — `NAME://host:port` mapped to a security protocol (ch18)
**Log compaction** — keeps at least the last value per key; offsets unchanged (ch01, ch07)
**min.insync.replicas** — minimum ISR size for `acks=all` writes to succeed (ch07, ch14)
**MirrorMaker 2** — Connect-based cross-cluster replication of topics, groups, offsets, ACLs (ch11)
**Pagecache** — OS file cache Kafka uses instead of heap cache (ch05, ch13)
**Partition** — ordered log unit of parallelism, per-key ordering and replication (ch01)
**Partition reassignment** — moving replicas with `kafka-reassign-partitions.sh` (ch10)
**Prefixed ACL** — ACL matching every resource name starting with a string (ch12, ch20)
**process.roles** — `broker`, `controller` or both (dev only) (ch15)
**Punctuator** — periodic PAPI callback on STREAM_TIME or WALL_CLOCK_TIME (ch26)
**Quota** — per-broker byte, request-% or `controller_mutation_rate` limit per user/client-id (ch07, ch10, ch12)
**Rack awareness** — `broker.rack` spreads replicas over racks/AZs (ch10)
**Record batch** — unit of append, compression and fetch (ch05, ch09)
**Record cache** — Streams per-thread cache compacting updates per key (ch25, ch27)
**Repartition topic** — internal topic shuffling records after a key change (ch23, ch25)
**Replication throttle** — bandwidth cap on reassignment traffic (ch10)
**SCRAM** — salted Kafka-managed passwords stored in KRaft metadata (ch19)
**Semantic partitioning** — hashing the key to choose a partition (ch05, ch08)
**Share group** — queue-style group with per-record acks; members can exceed partitions (ch03, ch06, ch10)
**Single Message Transform** — per-record Connect transform, optionally gated by a predicate (ch21)
**StandardAuthorizer** — default KRaft authorizer; ACLs in the metadata log (ch20)
**Standby replica** — shadow copy of task state on another instance (ch24, ch27)
**Static membership** — `group.instance.id` so restarts skip rebalances (ch05)
**Stream task** — unit of Streams parallelism owning fixed input partitions and state (ch24)
**Stream time** — data-driven time advancing only as records arrive (ch24, ch26)
**Stream–table duality** — a table is a stream's latest-per-key snapshot; a stream is its changelog (ch23, ch24)
**super.users** — principals bypassing all ACL checks (ch20)
**suppress** — buffers KTable updates for final window results or rate limiting (ch25)
**Tiered storage** — completed segments offloaded to remote storage via an RSM plugin (ch16)
**Tombstone** — keyed null-value record deleting the key; kept `delete.retention.ms` (ch07, ch25)
**TopologyTestDriver** — broker-less Streams topology test harness (ch28)
**Transactional producer** — `transactional.id` producer writing partitions + offsets atomically (ch06)
**Unclean leader election** — electing an out-of-ISR replica; may lose committed data; off by default (ch07)
**UnderReplicatedPartitions** — partitions with ISR < replica set; should be 0 (ch14)
**Versioned state store** — keeps timestamped versions per key for "as of" lookups (ch24, ch25, ch26)
**Warmup replica** — temporary standby restoring state before task migration (ch27)
**Zero-copy** — `sendfile` from pagecache to socket; off under TLS (ch05, ch09)
